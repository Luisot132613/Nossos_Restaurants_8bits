# Nossos_Restaurants_8bits

Página dedicada a Lívia, por sempre estar ao meu lado e me ensinar a aproveitar os momentos ao máximo.
Esse site tem o objetivo de identificar e salvar onde eu e a minha namorada já fomos durante nosso relacionamento.
E pode ser utilizado por qualquer pessoa que quiser guardar essas recordações, basta somente gerar uma API demo gratuita
do Google Places via [link](https://developers.google.com/maps/documentation/javascript/demo-key?hl=pt-br/) e colar na
opção "Configuração (Chave do Google)" para realizar as buscas em modo REAL, obtendo os restaurantes do mundo inteiro.
Na opção exportar e importar backup, também pode ser feito o download do arquivo .JSON e ser compartilhado com seu
amor, os locais salvos no navegador... gerando uma linha do tempo de dates especiais que já participaram ♥

---

## 📋 Funcionalidades
- Consulta de dados via API do Google Places para encontrar restaurantes no mundo inteiro.
- Exibição da lista de restaurantes salvos via cookies armazenados do site no navegador.
- Armazena locais obtendo as informações: nome, endereço, data do encontro, avaliaçao do casal e lembranças/prato.
- Função para cada pessoal adicionar sua API pessoal de forma segura, evitando ratreio e captura da mesma.
- Botão Import e Export de arquivo JSON, para backup dos lugares e notas salvas.
- Modo DEMO para representar as informações mesmo sem a chave API.
- Contagem dos locais que o casal já visitou com a média de corações das avaliações.
- Interface simples e responsiva em visual 8bits.

---

## 🚀 Tecnologias utilizadas
- **HTML** → estrutura da página  
- **CSS** → estilização  
- **JavaScript** → lógica e configurações da página 
- **Google Places API** → requisição via password para a chave não ficar salva no código
